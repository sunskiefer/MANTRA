MANTRA 0.2.0 for Akai Force / MPC OS (ARMv7). Rhythmic multi-effect: two layers of six effects, eight step modulators locked to the song, 24-slot matrix, preset manager.

**Testing status: offline only (2026-11-14). Not yet run on a real Force.**

- Flat dark panel, flat coloured tiles, top-lit knobs turning in place, Meta4MPCXXL text sizes
- Faders, key buttons, per-page randomiser
- Preset manager: 419 factory presets in 10 styles, unlimited user presets (SAVE / SAVE NEW / DELETE)
- Every factory preset runs 5-7 modulators and 10-18 routings
- Step faders jump to the touch (needs a device test)
- Fix: the preset list `<` `>` moved two or three pages on one tap; now one page per tap

Install: unzip, copy the folder to the device, run `install.sh` (see INSTALL.md in the zip). MPC OS 3.x.
