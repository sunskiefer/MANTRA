MANTRA data folder.
  user/       your own presets (one .mnt file each: back it up, copy it to another unit). Written by SAVE / SAVE NEW on the PRESETS page.
  touch.log   what the step-fader touch reader saw (made at start).
  touch.off   create an empty file with this name to switch the step-fader touch off.
This folder is kept when the plugin is updated.
